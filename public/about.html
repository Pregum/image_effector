NOIZ LAB

ブラウザだけで完結する、
画像エフェクトの実験室

写真やイラストにグリッチ・ピクセルソート・ディザ・CRT・フィルム調などをかけて、サムネイルやリール用の縦動画まで書き出せるツールです。インストール不要・ログイン不要・無料で、加工処理はすべてあなたのブラウザの中で動きます。

できること／ 主な機能

エフェクト
11種類を自由に重ねられる ぼかし / ピクセルソート / グリッチ / 色収差 / ハレーション / 色調エモ化 / 光漏れ / モザイク / ディザ・網点・アスキーアート / CRT湾曲・走査線・VHSトラッキング / 粒子・ビネット。Y2K・VHS・CINEMA・FILM・NEONなど9プリセットからワンタップでも。
素材づくり
手持ちの画像がなくても始められる コードで描いたサンプル画像が8種類。さらにテキストから「写真」(FLUX.1) と「シーン」(AIが設計図を書き、ブラウザがベクター風に描画) の2通りで生成できます。日本語でどうぞ。
仕上げ
サムネイルとして完成させる タイトル文字入れ（フォント・色・自由配置、ドラッグで移動）、2枚目の画像を重ねるコラージュ、16:9 / 1:1 / 9:16 の中央クロップ書き出し。
動画
リール・ショート向けの縦動画まで 最大8カットを並べ、フェード / ワイプ / ディゾルブ / グリッチワイプ + ズーム演出でつなぎます。BGMを入れるとBPMを自動検出して拍に合わせたカット割りに。MP4(H.264)で書き出すのでそのまま投稿でき、GIFにも対応。
ギャラリー
作品を貯めて、次の一手を見つける 作った画像とエフェクト設定を保存でき、似た作品同士を線でつないだ2D/3Dのグラフで眺められます。2作品を掛け合わせて新しい作品を生んだり、「まだ埋まっていない場所」から次に作ると良い作品を提案させたりできます。

画像の扱い／ プライバシー

読み込んだ画像は、あなたのブラウザから出ません

  • ✓エフェクト・文字入れ・動画やGIFの書き出しは、すべて端末内で処理されます。画像がサーバーに送られることはありません。
  • ✓サーバーに保存されるのは、あなたが自分で「ギャラリーへ保存」を押した作品だけです。
  • ✓保存した作品も既定では非公開です。持ち主以外は画像を開けません。
  • ✓他の人に見せたいときは作品ごとに共有リンクを発行できますが、共有は約1日で自動的に切れます。それ以降はリンクを知っていても開けません。

AI生成を使うときだけ、入力した文章（プロンプト）がCloudflareのAIに送られます。画像そのものを送るAI機能はありません。

無料である理由／ 課金なし・広告なし

無料枠の中だけで動くように作ってあります

  • ✓Cloudflareの無料枠だけで完結する構成で、そもそも課金が発生し得ないように設計しています。
  • ✓広告もトラッキングもありません。アカウント登録も不要です。
  • ✓AI生成には1日あたりの上限があります。使い切った日は翌朝（日本時間9時ごろ）にリセットされます。エフェクト機能は上限に関係なくいつでも使えます。

技術／ どう作られているか

画像処理は WebGL2 のシェーダーで、ピクセルソートやGIFエンコーダ（LZW・減色）、ナレッジグラフの力学シミュレーションまで含めて外部ライブラリを使わずに実装しています。サーバーは Cloudflare Workers 一枚で、AI生成に Workers AI、作品の保存に R2 と D1、レート制限に Durable Objects を使っています。
